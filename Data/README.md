# Data

`Spec*.lua` (specialization node stats per recipe, Midnight) and `ConcentrationCurves.lua`
(Concentration cost curves) are generated by `tools/convert_craftsim.py` from
[CraftSim](https://github.com/derfloh205/CraftSim), MIT licence, copyright (c) derfloh205.
The profit, Multicraft, Resourcefulness, Ingenuity and Concentration formulas in `Stats.lua`
follow CraftSim's.

To refresh after a patch: `python3 tools/convert_craftsim.py "<WoW>/_retail_/Interface/AddOns/CraftSim"`.
