### Local files that aren't in the repo

These are left over in the install folder from older builds. None is listed in a TOC, so the game
never loads them. They're safe to delete.

- `AuctionIQ/Accounting/ReportUI.lua`
- `AuctionIQ/Operations/Craft/PathsUI.lua`, `Presets.lua`, `TreeView.lua` (now in `AuctionIQ_Paths`)
- `AuctionIQ/Operations/Trade/Banking.lua`, `Vendoring.lua` (removed in #152 and #153)
- `AuctionIQ/Operations/Craft/Specs/` (now the `AuctionIQ_<Profession>` addons)
- `AuctionIQ/Media/Accounting.tga`, `Clearinghouse.tga`, `Icon-IQ.tga`, `Tab-Research.tga`

A new harness check (`toc: ...`) now fails if a Lua file in the repo isn't in its TOC, or the
reverse, so the release package can't ship a file that doesn't load.
